# Daily Goals (React)

A clean, responsive Daily Goals web app built with React, Hooks, and LocalStorage.

Features
- Add goals with title (required) and optional description
- Mark goals complete/incomplete
- Edit and delete goals
- Persistent storage via LocalStorage
- Progress bar and today's date
- Responsive card-based UI with smooth transitions

Quick start

1. Install dependencies:

```bash
npm install
```

2. Run in development:

```bash
npm run dev
```

Open the printed local URL (usually http://localhost:5173) in your browser.

Build for production:

```bash
npm run build
npm run preview
```
